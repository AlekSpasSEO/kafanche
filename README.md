# КафанЧе

Responsive one-page website for КафанЧе in Skopje, published with GitHub Pages.

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Content

- Four current menu PDFs supplied by the business
- Google reviews, Google Maps, Waze, Instagram, Wolt and Korpa links
- LocalBusiness/Restaurant structured data
- Responsive navigation and live opening-status indicator for Europe/Skopje

Brand assets and menus are supplied by КафанЧе. Initial venue photography is sourced from the business's public Tripadvisor listing and should be replaced with the original business files before final commercial launch.
